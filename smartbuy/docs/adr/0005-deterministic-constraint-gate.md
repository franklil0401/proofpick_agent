# ADR-0005：不可绕过的确定性硬约束安全门

- 状态：已接受
- 日期：2026-08-27
- 决策范围：阶段 5 约束来源、完整候选池复核、LLM 权限边界与报告集成

## 背景

阶段 4 已能通过 ReAct 调用 Text2SQL、KB Search 和 Evidence Check，但最终资格仍可能受模型解析和候选保留行为影响。真实失败 `s4-014` 中，用户没有提出尺寸要求，模型却加入尺寸条件并提前淘汰正确型号。仅加强 Prompt 不能证明此类错误不可绕过，因此最终推荐前必须增加独立、确定性且 fail-closed 的安全门。

## 决策

1. 建立类型化 `ConstraintSet`。每条约束记录字段、操作符、归一值、单位、硬/软类型、来源、原文、轮次、置信度、支持状态和启用状态。
2. 来源优先级固定为当前输入 > 会话确认条件 > 已启用长期偏好 > 系统默认。工具结果、商品资料和模型推测不能反向成为用户约束；当前输入可覆盖或取消记忆条件。
3. 首批确定性字段限于价格、尺寸、分辨率、刷新率、OLED、USB-C、USB-C 视频、供电功率、机身宽度、品牌和支架能力。模糊或未支持表达显式返回 `unsupported/ambiguous`，不静默忽略。
4. `CandidateConstraintVerifier` 在 ReAct 结束后强制运行，不注册为 LLM 可选工具。输入是工具阶段累计的完整稳定 `model_id` 候选池，而不是模型最终保留列表。
5. Checker 使用只读 SQLite、参数化字段读取、表内稳定 `model_id` 和同型号同地区 `evidence_records`。它不执行模型生成代码、不写数据库，也不解释网页中的指令。
6. 每个硬约束产生 `passed/failed/unknown/conflict`。全部硬约束 `passed` 才能 `eligible=true`；任一失败、未知、冲突、未支持或歧义均不能成为完全满足。
7. 价格只使用当前地区最新可用观测，并检查 `observed_at` 与 30 天时效。没有价格或过期价格为 `unknown`，不宣称实时。
8. 错误型号、数据库外型号和重复型号均 fail closed。Checker 异常时对整个候选池返回降级结果且不推荐。
9. LLM 只可对完整 `eligible_model_ids` 集合按受支持软偏好排序和解释。代码会移除集合外新增项，并自动补回模型遗漏的合规项，因此 LLM 不能增删资格或覆盖字段状态。
10. Checker 输出版本、时间策略、语义指纹、候选池、字段实际值、要求值、证据 ID、来源 ID和降级状态。相同输入、固定数据和固定 `as_of` 必须得到字节等价结果。
11. SSE 新增 `constraint_check_started/completed`；WebUI 与 Monitor 只展示公开字段结果，不展示隐藏思维链、完整 Prompt、凭据或敏感错误正文。

## 归一化契约

- 数值边界使用包含关系：`<=`、`>=` 和范围两端均包含。
- `4K/UHD/3840×2160` 归一为 `3840x2160`；`2K/QHD/WQHD/2560×1440` 归一为 `2560x1440`。
- “不要 OLED/非 OLED”归一为 `is_oled == false`；“至少/不低于 90W”归一为 `usb_c_power_delivery_w >= 90`。
- cm 可换算为 mm；未知值保持 `null`，不得用 0 代替。
- “27 寸左右”记为歧义软偏好，需要确认后才能成为硬条件。
- 来源证据中的 Prompt 注入文本只作为原始说明保存，不参与规则计算。

## 未采用方案

- 只用 Prompt 禁止模型改约束：无法提供不可绕过保证，且 `s4-014` 已给出反例。
- 只检查模型最终候选：无法恢复被模型提前误杀的完整工具候选。
- 用 Reranker 分数做资格阈值：相关性不等于字段满足，阶段 3 的拒答基线已证明不足。
- 把所有模糊语言硬编码为规则：边界不可维护；当前选择缩小受支持词表并显式返回未支持项。
- 用 LLM 生成最终字段状态：结果不可重复，也无法证明不会覆盖 SQLite 和证据。

## 影响

- 正向：阶段 4 固定候选池上的任务级硬约束正确率从 10/12 提升为 12/12，恢复 3 个合规候选；12 个故障注入候选全部拦截，合规候选误杀率为 0。
- 性能：Checker 纯本地执行，固定自然套件平均/P95 为 1.332/1.994 ms；完整在线 E2E 平均/P95 为 2.014/4.975 ms，不产生 API 调用或模型成本。
- 代价：受支持自然语言范围是显式白名单；未支持或歧义约束会拒绝完全满足，可能需要用户补充。
- 边界：这不是阶段 6 的四组完整消融、重复运行、缓存或综合故障矩阵；GraphRAG 和真实 Web Search 仍未实现。

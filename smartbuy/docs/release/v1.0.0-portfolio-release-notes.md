## ProofPick Portfolio MVP

ProofPick 是一个基于 Agentic RAG 的多源消费决策 Agent。当前 `SmartBuy` 场景聚焦中国大陆显示器选购：Agent 使用有界 ReAct 编排只读 Text2SQL、KB Search 与四态 Evidence Check，并在最终输出前经过不可由 LLM 覆盖的确定性 Constraint Checker。

### 主要能力

- qwen-plus Tool Calling 驱动的有界 ReAct 与依赖式多跳检索。
- text-embedding-v4（1024 维）向量召回 + qwen3-rerank 二阶段排序。
- 只读安全 Text2SQL、字段级证据追踪与分层偏好 Memory。
- 从完整候选池执行的确定性硬约束复核，异常时 fail closed。
- 四组公平评测、统一账本、安全缓存、受控故障注入与 Windows 复现脚本。

### 可复核结果

- 40 条冻结任务 × 3 次：Fixed RAG 51/120（42.50%），Agentic RAG + Checker 92/120（76.67%），提高 34.17 个百分点。
- 36 条人工核验检索用例：Recall@5 从 89.12% 提升至 98.38%。
- 阶段 6 增强组首次自然任务：违规候选推荐 0/43，仅适用于当前数据版本和支持字段。
- 阶段 7 发布质量门：95 tests passed；发布候选单次 34/40。

以上均为作品集/MVP 实验结果，不是生产准确率、生产零违规承诺或 SLA。

### 已知限制

- 当前仅覆盖 12 个治理显示器型号，不支持全品类。
- Web Search 只有 unavailable/degraded 接口；4 条离线价格观察不代表实时价格或库存。
- GraphRAG、Neo4j、自动下单、公网多租户和生产级高并发未实现。
